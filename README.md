# StarTrekTrackerMobile
This is a mobile version of my previous project, [StarTrekTracker](https://github.com/SLineham29/StarTrekTracker), with a new UI that uses an LCARS-inspired colour scheme and design.

Much like my original project, I created this as a way to learn mobile development, specifically Kotlin, so the project design may have some quirks/inconsistencies.

> [!WARNING]
> If you would like to build and use this app for yourself, you will need to place your own TMDB API key in a `local.properties` file in the root of the project using the following:
> ```
> TMDB_API_KEY=YourKeyHere
> ```

This product uses the TMDb API but is not endorsed or certified by TMDb.
More information about TMDb can be found on their [website](https://www.themoviedb.org/).
